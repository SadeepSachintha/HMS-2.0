## Reporting a Vulnerability

We take the security of the Hotel Management System (HMS 2.0) seriously. If you discover a security vulnerability within this project, please do not open a public issue. 

Instead, please report it using one of the following methods:
* **GitHub Private Vulnerability Reporting:** Navigate to the **Security** tab of this repository, select **Advisories**, and click **Report a vulnerability**.
* **Direct Contact:** Reach out directly to the maintainer via the contact information listed on the [@SadeepSachintha](https://github.com/SadeepSachintha) GitHub profile.

**What to expect:**
* You will receive an acknowledgment of your report within 48 hours.
* We will triage the issue and determine the severity and impact.
* If the vulnerability is accepted, we will work to patch it and release a security update as quickly as possible.
* You will be kept informed of the progress and credited in the release notes once the issue is resolved and safely disclosed.
